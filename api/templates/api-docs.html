API Documentation

The UK Bin Day API returns household waste and recycling schedules for UK addresses, given a UPRN. It is available at https://ukbinday.co.uk/api/v2 and is completely free

Full reference documentation is generated from the OpenAPI schema:

  • Swagger UI - try endpoints in the browser.
  • ReDoc - single-page reference view.
  • openapi.json - raw schema.

Subscribing to bin collections

For most people, the easiest way to use this service is to subscribe to the iCalendar feed for your address. Collections then appear automatically in your calendar app and update as new dates are scraped.

Find your address on the home page and click the subscribe link, or build one directly: 

https://ukbinday.co.uk/api/v2/{lad_code}/subscribe/{uprn}?postcode={postcode}

/api/v2/{lad_code}/download/{uprn} serves the same calendar as a file download.

Programmatic access

If you need JSON instead of a calendar feed, call /api/v2/{lad_code}/view/{uprn}?postcode={postcode}. It answers with the collection dates in ascending order, each with its bin type, the bin colour where the council's label names one, and the bank holiday the date falls on, if any.

{lad_code} is the council's ONS LAD code, for example E06000001 for Hartlepool. /api/v2/councils lists every supported code with the parameters each council needs. Some councils also need address, house_number or street.

Cache misses trigger a live scrape of the council website and may take several seconds; subsequent requests return immediately.

/api/v2/find resolves a postcode to its council for anyone. Its address list (the UPRNs) is behind a browser challenge and is meant for this site's own frontend; without the challenge token addresses is null.

Terminology

UPRN

Unique Property Reference Number. A 12-digit identifier for a specific UK address.

Local Authority District (LAD)

The council responsible for waste collection at an address, identified by its ONS LAD code. It is the {lad_code} segment of every lookup path. Councils that share one collection service (Adur and Worthing) keep separate codes.
